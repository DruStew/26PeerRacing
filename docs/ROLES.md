# Roles

High-level role capabilities. Exact permissions are enforced by Supabase RLS.

## Runner

- Access own profile and participation data
- View events they are eligible for

## Promoter

- Manage events they own or are assigned to
- View participant lists for their events

## Booth

- On-site operations for assigned events
- View and update participant check-in status

## Admin

- Full access across all events and users
- Configure system-wide settings
